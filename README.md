## 🛠️ Local Developer Diagnostics
This interface is engineered completely mobile-first and fluidly responsive using standard React 19 architecture and flat native CSS design tokens.

### Running Local Development Environment
To start the live reload sandbox server locally, run these terminal commands inside the workspace folder directory:
```bash
cd thesis-dashboard
npm install
npm run dev
```

### Production Application Deployment
To compile the production build folder and automatically synchronize the deployment branch, run:
```bash
npm run deploy
```
